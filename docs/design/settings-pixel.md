# 设置页：精致像素

设置属于照料时刻。保留 4+1 分区和所有现有保存、权限、记忆删除逻辑，用清晰的原生控件承载像素品牌。

## 组件与资源

- `app/frontend/css/settings-pixel.css`：只由 settings.html 引入。主题覆盖层与旧布局隔离，不改变其他窗口的共享色值。
- `app/frontend/assets/settings/bitcat.svg`：32 × 32 网格的黑白像素猫标识；40px 展示，纯装饰图片使用空 alt。
- `app/frontend/assets/settings/resting-cat.svg`：48 × 28 网格的休息猫，侧栏底部装饰，不代表实时运行状态。
- `app/frontend/assets/settings/icons.svg`：24 × 24 SVG symbol 库，统一 2 单位描边。显示器对应权限、记事本对应记忆、金币对应用量、爱心对应陪伴、齿轮对应专家。另含摄像头、统计、盾牌、连接、箭头。
- `.pixel-icon`：使用 `<svg class="pixel-icon" aria-hidden="true"><use href="/assets/settings/icons.svg#monitor"></use></svg>`；标签承担可访问名称，图标不重复朗读。
- `.nav-item`：默认 / 悬停 / 当前 / 键盘焦点 / 未保存状态。当前页使用 `aria-current="page"`，窄窗口隐藏文字时仍保留 aria-label。
- 设置行：标签、说明、右侧控件。分组内只用细横线分隔；权限开关 42 × 24px，关闭为中灰、开启为森林绿。
- 按钮：主操作为绿色实底；普通操作为白底细边；危险操作为暗红文字。统一 6px 圆角，保留加载与禁用反馈。
- 记忆列表：扁平条目、淡绿标签、明确的“删除”按钮，保留原文展开与删除确认。
- 猫咪选择：大预览 + 可滚动品种列表，使用真实宠物素材。选择尚未保存时只更新预览；异步旧结果不会覆盖新选择。沿用方向键移动焦点及 Enter / Space 选择。

## 视觉约定

| 用途 | 色值 |
| --- | --- |
| 页面 | `#FAFBFA` |
| 侧栏 | `#F0F3F0` |
| 正文 | `#24332D` |
| 说明 | `#5B6B62` |
| 主操作 | `#28764F` |
| 选中背景 | `#DCEBE1` |
| 分隔线 | `#E0E6E2` |

正文沿用项目中文字体，不使用像素字。标题 26px、正文 14px、辅助文字 12px；像素仅用于标识与图标。控件显示明确的键盘焦点，遵循减少动态效果设置。标准窗口为 1040 × 720；900px 以下收紧布局，680px 以下侧栏切为保留名称的图标导航。

预览稿中的搜索、导出和虚构金额不作为新增能力接入；继续展示实际已有数据与操作。宠物资源保持项目原有形象，没有用设计稿的猫替换运行时素材。

## 产品自检

- 时刻：照料；陪伴页涵盖互动外观设置。
- 四个疑问：权限、记忆、用量保持明确分区；收权入口优先留在标准窗口首屏。
- 预算：新增交互入口 0，删除交互入口 0；增加的预览与装饰均不可交互，既有控件预算未扩大。
- 文案：品种名中文化；“保存”改为“保存设置”，“×”删除改为“删除”。
- 恐慌测试：不更改默认能力和权限，不增加观察或联网能力。
- 验证：前端 Vitest；静态浏览器检查五个分区、向导、选择、保存及窄窗口。Tauri 原生窗口待 Windows 实机确认。

## 概览与底栏精简

概览使用两行紧凑排版：配置状态以标题旁的绿点 / 琥珀点表示，并保留可访问名称和悬停说明；屏幕观察以灰点 / 绿点配合“关闭 / 开启”，说明移至悬停提示；记忆数量合并为“2 件事”。底部操作区无分隔线，恢复默认与取消使用轻量文字按钮，保存使用浅绿底。交互入口与权限默认值不变。

## 记忆信息密度与连接表单

记忆时间、来源、五段重要程度条与标签使用同一条弹性信息行，窄窗口或长标签自然换行。重要程度范围为 1–5，悬停和辅助技术提供精确值；缺失与越界值显示空心段，明确为“尚未评估”。时间显示相对时间，悬停保留原始记录时间。列表汇总与提醒元信息去掉多余徽章底色。连接表单取消外框、行间横线及当前配置值旁竖线，保留输入框边界与焦点反馈。控件数量不变。

## 标题与用量分布

页面标题与说明基线对齐，空间不足时自然折行。记忆数量和更新时间直接放在分区标题旁。统计卡片取消固定最小高度。用量分布采用 SVG 环形图与右侧明细列表，不增加图表依赖；图表展示用量占比而非虚构金额，零用量显示中性空环，未分类差额显示为“其他”。

排版数值以 [统一文字规范](typography.md) 和 `typography.css` 为准，本文件不再维护独立的字号、字重及行高取值。

## 可互动的猫咪选择预览

标准窗口的左预览宽 184px，右侧采用最小 78px 的自适应网格；去掉推荐/猫咪/其他分组的空行，1040px 窗口可显示六列、三行的全部 17 个选项。窄窗口保留滚动和单列布局，方向键上下按实际网格列数移动焦点。

点击或用 Enter / Space 激活预览，依次展示素材中实际存在的待机、开心、走路、睡觉、说话、专注、困惑和胜利状态。拖动有小幅跟随和现有 dragging 动画，松手播放开心状态。所有动画使用 manifest 的帧索引与时长，不发送桌宠命令，也不修改品种或其他设置。

每次最多播放 5 秒。换品种、离开陪伴页、隐藏页面、页面退出时停止；减少动态效果模式仅展示静态姿态。缺少的状态跳过，加载失败禁用互动并明确提示。控件变化：现有静态预览增加一个用户明确要求的互动入口，无额外动作按钮或设置项。
