# 对话气泡配色

颜色表达文字层级、可操作性和执行结果。基础是暖白纸面与深墨正文，角色和情绪由猫、文字与反应共同表达。

## 颜色角色

| 内容 | 当前颜色 | 用途 |
| --- | --- | --- |
| 气泡底色 | `#fffdf2` | 稳定阅读背景 |
| 猫的正文与列表符号 | `#262119` | 回复和内容结构 |
| 用户消息 | `#4a4035`，浅褐底 | 与回复区分 |
| 普通进度与辅助操作 | `#716954` | 次要信息 |
| 发送、链接与焦点 | `#315fb8` | 操作强调与键盘定位 |
| 权限限制与等待确认 | `#75511a`，琥珀轻底 | 说明需要确认或受到限制 |
| 执行失败 | `#8f2f22`，砖红轻底 | 明确操作没有完成 |
| 复制成功 | `#3f5d2f` | 勾短暂确认结果，随后恢复普通复制图标 |

普通工具进度统一使用辅助文字色。成功完成的普通进度按状态协议退出；复制的勾与已有完成通知使用绿色。色彩之外保留状态文字、符号和辅助标签。

## 实现约束

- 唯一实现来源为 [`bubble.css`](../../app/frontend/css/bubble.css)。沿用 `--bubble-warm` / `--bubble-warm-ink`、`--bubble-danger` / `--bubble-danger-ink` 和 `--bubble-success-ink`。
- 权限限制的背景为 `--bubble-warning-surface: rgba(212, 165, 72, 0.09)`；等待确认通知边界为 `--bubble-warning-line: rgba(212, 165, 72, 0.4)`。
- `blocked` 和 `failed` 使用不同颜色，但都保留完整正文说明；发送失败继续用错误色。
- 列表符号与正文同色，链接继续用操作色。
- 复制成功颜色直接作用于勾的 SVG，悬停或键盘焦点不会把它覆盖成普通图标色。

## 验证

按当前 CSS 颜色与暖白底合成计算，权限限制文字对比度约 6.54:1、执行失败文字约 7.16:1、复制成功勾约 7.30:1。普通文字以 [W3C 的 4.5:1 基准](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)检查；这些数值是所列状态的颜色验证，不代表完整可访问性验收。

浏览器确认了权限限制与失败的颜色区别、列表符号与链接的区别，以及复制成功在键盘聚焦时的绿色反馈。对话回归 75 项与共享排版检查通过。局域网预览中的“文件访问受限”和“提醒失败”可用于对照，均不执行真实操作。

## 产品自检

- 时刻：互动与陪伴中的状态呈现。
- 四个疑问：“它刚才干了什么”更清楚，限制、失败和成功反馈具有不同含义。
- 预算：产品入口与控件 +0 / -0；仅补充开发预览场景。
- 文案：产品文案保持原有表达。
- 恐慌测试：不改变授权、观察、费用或默认能力。
