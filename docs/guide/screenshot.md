# 截图观察

8Bit Cat 会在后台定时截图并使用 Vision API 分析屏幕内容，让 AI 了解你正在做什么。

## 工作方式

程序运行一个独立的后台线程，按配置的间隔（默认 30 秒）执行以下流程：

```
定时截图 → 熄屏检测 → dHash 去重 → 缩放 → JPEG 编码 → Vision API 分析 → 保存结果
```

### 自动跳过的情况

以下情况截图线程会自动跳过本轮：

- **显示器关闭或休眠**：通过 `GetSystemMetrics(SM_MONITORISOFF)` 检测
- **全黑帧**：采样 256 个像素，超过 95% 为纯黑（覆盖屏保/锁屏）
- **正在 AI 对话**：聊天输入框展开或流式回复进行中
- **正在跳舞**：舞蹈播放期间
- **画面未变化**：dHash 感知哈希相似度超过 95% 时跳过，避免重复分析

这些跳过机制可以节省 Vision API 调用费用。

## 分析结果

每次截图分析会生成两个文件保存在 `~/.ai-pad/screenshots/` 目录：

```
screenshots/
└── 2026-05-13/              # 按日期分目录
    ├── 143022.jpg            # 缩放后的截图（JPEG，质量 80）
    └── 143022_analysis.json  # Vision API 分析结果
```

分析结果包含 AI 对屏幕内容的描述（当前活动、识别到的应用、屏幕状态等）。

### 上下文注入

AI 对话时会自动注入两个来源的屏幕信息：

1. **最近 10 条截图原始分析记录**（总字符预算 1500 字符）
2. **屏幕活动摘要**：定时将截图分析汇总为结构化摘要

这让 AI 能了解你最近在做什么，提供更相关的回复。

## 多显示器支持

如果你有多个显示器，程序会将所有显示器画面水平拼接后一起分析。

截图分辨率默认缩放到最大宽度 **960px**，在保持宽高比的前提下节省 Vision API 的图片 token 消耗。

## 手动截图

除了自动定时截图，你还可以通过系统托盘菜单、手柄动作或全局快捷键手动触发：

右键托盘图标 → **"立即截图"**

默认按键绑定：

- 手柄 `R2`
- 键盘 `CommandOrControl+Alt+S`

也可以在 `config/actions.yml` 中把任意按键配置为：

```yaml
R2:
  type: screenshot
  keyboard_shortcut: "CommandOrControl+Alt+S"
```

手动截图会立即执行一次完整的截图 + 分析流程，不受定时间隔限制。

## 存储与清理

- 截图和分析文件按日期存放在 `~/.ai-pad/screenshots/YYYY-MM-DD/` 目录
- **7 天自动清理**：每天运行时自动删除超过 7 天的日期目录
- 文件命名格式为 `HHMMSS.jpg` 和 `HHMMSS_analysis.json`

## 配置

在设置窗口的"外观行为"标签页中可以调整：

| 配置项 | 默认值 | 范围 | 说明 |
|--------|--------|------|------|
| 截屏分析间隔 | 30 秒 | 5 ~ 3600 秒 | 每次截图的间隔时间 |

修改后**即时生效**，截图线程每轮重新读取配置。

也可以通过 `config/prompts.yml` 中的 `screen_summary` 段调整屏幕摘要的注入条数和聚合间隔。

## 截图线程的暂停机制

截图线程在以下场景自动暂停，结束后自动恢复：

| 场景 | 暂停方式 |
|------|---------|
| AI 对话进行中 | `chat_active` 标志位控制 |
| 舞蹈播放中 | `IS_DANCING` 全局原子标志 |
| 显示器关闭 | `SM_MONITORISOFF` 系统指标 |

这些保护确保在不需要分析时不会浪费 Vision API 调用。
