# 截图观察

8Bit Cat 会在后台定时截图，用 Vision 模型分析屏幕内容，让对话能理解你最近在做什么。截图分析结果会保存到本地，并可作为 AI 上下文或工具查询来源。

## 工作流程

```text
定时触发
  → 熄屏/黑屏检测
  → dHash 去重
  → 多显示器拼接
  → 缩放到最大宽度
  → JPEG 编码
  → Vision Extractor 结构化分析
  → 保存图片和 analysis.json
  → 必要时显示气泡
```

默认间隔是 30 秒，可在设置页“外观与行为”调整。

## 自动跳过场景

以下情况会跳过本轮截图，避免浪费 token：

- 显示器关闭或休眠。
- 采样判定为几乎全黑。
- AI 对话正在进行。
- 舞蹈正在播放。
- 画面和上一帧高度相似，dHash 判定未明显变化。

## 保存位置

```text
~/.ai-pad/screenshots/YYYY-MM-DD/
├── HHMMSS.jpg
└── HHMMSS_analysis.json
```

截图文件 7 天自动清理。分析结果是结构化 JSON，包含屏幕描述、确认可见文本、不确定文本、推断活动、风险标记和置信度等字段。

## 多显示器

多显示器会横向拼接后一起分析。提示词要求模型不要假设左边一定是副屏或右边一定是主屏，只按可见内容描述。

## 手动截图

可通过以下方式立即截图：

- 托盘菜单 → “立即截图”
- 默认手柄 R2
- 默认快捷键 `CommandOrControl+Alt+S`
- 点击猫咪左眼附近的隐藏调试入口，当前前端会调用 `cmd_screenshot_now`

手动截图会立即执行完整截图 + 分析流程，不受定时间隔限制，但仍会复用安全检查和存储路径。

## 对话中的使用

AI 有 `recent_screenshots` 工具。你可以问：

- “我刚才在看什么？”
- “总结一下最近屏幕活动”
- “刚才那个页面里有什么明显内容？”

请注意，Vision 提示词刻意保守：看不清的文件名、歌名、数字和媒体元数据会进入不确定字段，不会当作确定事实写进描述。

## 屏幕活动摘要

除了原始截图分析，系统还会按 `config/prompts.yml` 的 `screen_summary` 设置，把近期截图分析聚合成结构化活动摘要：

```yaml
screen_summary:
  interval_min: 15
  max_recent_analyses: 30
  max_context_entries: 20
  max_context_chars: 2000
```

摘要用于让 AI 了解最近一段时间的活动，而不是每次都塞入大量截图细节。

## 降低消耗

- 增大截图间隔。
- 保持 dHash 去重开启。
- 不需要屏幕观察时可把间隔调大到几分钟。
- 在设置页“用量统计”查看 vision 和 screen_summary 的 token 占比。
