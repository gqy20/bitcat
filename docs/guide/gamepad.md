# 手柄操作

8Bit Cat 原生支持蓝牙手柄操作。以 8BitDo Micro 为参考，其他 SDL2 兼容手柄（Xbox、DualSense 等）也可使用。

## 配对手柄

以 8BitDo Micro 为例：

1. 将手柄背面模式开关拨到 **D**（D-Input 模式）
2. 按住 Pair 按钮 1 秒，LED 快闪
3. Windows 蓝牙设置中搜索配对
4. 首次使用方向键需激活：**按住 Select + 上方向键 五秒**

配对完成后，启动 8Bit Cat 会自动检测手柄。

## 手柄自动识别

程序会自动过滤键鼠接收器等非手柄设备，按以下优先级选择手柄：

1. 名称包含 `controller`/`gamepad`/`8bitdo`/`xbox`/`dualsense` 等关键词的设备
2. 有方向键（hat）或至少 2 个摇杆轴的设备
3. 第一个非键鼠设备

支持热插拔：手柄断开后每隔约 1 秒检测重连，重连后自动恢复。

        │       L1          R1     │
        │       L2          R2     │
        │                          │
        │   ┌───┐                  │

        │ ┌─┼───┼─┐     ┌─┤ X ├─┐ │
        │ │←│   │→│     │ ├───┤ │ │
        │ └─┼───┼─┘     │ │ Y │ │ │
        │   │ ↓ │     ┌─┤ ├───┤ ├─┐
        │   └───┘     │ │ A │ │ B │
        │             └─┴───┴─┴───┘│

### 按键编号（D-Input 模式）

| 编号 | 名称 | 面板外功能 | 面板内功能 |
|------|------|-----------|-----------|
| 0 | **A** | 夸奖猫咪 → AI 说"喵~ 谢谢夸奖！"，Happy 状态 | 确认选择 |
| 1 | **B** | 随机走动（走到屏幕随机位置） | 关闭面板 |
| 4 | **Y** | 短按：触发舞蹈播放；按住：语音输入 | — |
| 6 | **L1** | Alt+Tab（切换窗口） | — |
| 7 | **R1** | Alt+\`（打开 uTools 等工具） | — |
| 8 | **L2** | Ctrl+Tab（切换标签页） | — |
| 10 | **Select** | 切换睡眠/唤醒 | — |
| 11 | **Start** | 与 AI 对话 | — |
| 12 | **Home** | 弹出/关闭面板 | — |

L1/R1/L2 的具体功能由 `config/actions.yml` 配置，上方为默认值。

## 方向键行为

方向键的用途取决于面板状态：

### 面板关闭时 → 桌面滚动

方向键映射为鼠标滚轮操作，每 80ms 持续触发：

| 方向 | 效果 |
|------|------|
| 上 / 下 | 垂直滚动（3 倍速度，每次 360 units） |
| 左 / 右 | 水平滚动（同上） |

松开方向键时自动释放 Alt+Tab / Ctrl+Tab 的修饰键状态。

### 面板弹出时 → 面板导航

| 方向 | 效果 |
|------|------|
| 上 / 下 / 左 / 右 | 移动选中项（蓝色光晕高亮） |
| A / Enter | 确认选中项 |
| B / Esc | 关闭面板 |

面板可见时，A/B/方向键**由面板独占**，不会触发 actions.yml 中绑定的动作。

## 按键处理优先级

按键按下时，程序按以下顺序处理（高优先级先拦截）：

1. **Home 键** → 直接切换面板，跳过后续所有处理
2. **面板可见** → A 确认 / B 关闭 / 方向键导航，其他按键忽略
3. **Bridge 层** → Start 触发 AI 对话 / Select 切换睡眠 / A 夸奖 / B 走动 / Y 舞蹈
4. **actions.yml** → L1/R1/L2 等执行配置的动作

每个按键只在**按下的瞬间**触发（上升沿检测），按住不会重复触发（Voice 按住例外）。

## 自定义按键绑定

所有手柄按键都可以通过 `config/actions.yml` 重新绑定。支持四种动作类型：

```yaml
actions:
  L1:
    type: hotkey
    trigger: ["alt", "tab"]       # 发送键盘组合键

  Start:
    type: launch
    program: claude               # 启动程序
    args: "--dangerously-skip-permissions"
    terminal: true                 # 在终端中运行

  Y:
    type: voice
    voice:
      trigger: ["ctrl", "win"]    # 输入法语音热键
      delay: 1.0                  # 延迟秒数

  R2:
    type: script
    command: "python my_script.py" # 执行 PowerShell 命令
```

详见 [configuration.md](configuration.md)。
