# 常见问题

## 安装与启动

### 启动后没有看到猫咪

- 检查系统托盘区域是否有猫咪图标
- 猫咪默认出现在屏幕角落，可能被其他窗口遮挡
- 如果开启了"启动时折叠"，猫咪以竖条形态显示在屏幕边缘，点击竖条恢复

### 启动报错 / 闪退

- 以 `--debug` 参数启动查看控制台日志：`ai-pad-app.exe --debug`
- 日志文件位于 `~/.ai-pad/logs/`，按日期滚动
- 确认 WebView2 已安装（Windows 11 自带；Windows 10 从微软官网安装）

## 手柄

### 手柄配对后不响应

- 确认手柄模式为 **D-Input**（8BitDo Micro 拨到 D）
- 方向键首次使用需激活：**按住 Select + 上 五秒**
- 查看日志确认手柄是否被识别（debug 模式下会打印设备列表）

### 手柄按键功能不对

- 不同手柄的按键编号可能不同，`config/buttons.yml` 默认按 8BitDo Micro 校准
- 用 `--debug` 模式启动，按下按键时日志会显示编号
- 根据实际编号修改 `buttons.yml`

### 手柄断连后无法重连

- 程序支持热插拔，断开后每约 1 秒自动尝试重连
- 如果长时间无法重连，尝试关闭手柄再重新开启
- 检查蓝牙设置中手柄是否仍为已配对状态

## AI 对话

### 对话没有响应

- 确认已配置 API Key（见设置窗口 → AI 模型）
- 检查网络连接
- 如果使用代理，确认 `ANTHROPIC_BASE_URL` 配置正确
- 查看 `~/.ai-pad/logs/` 日志中是否有错误信息

### AI 回复很慢

- AI 回复使用流式输出，第一个 token 通常在 1-3 秒内出现
- 如果长时间无响应，可能是网络问题或 API 服务端过载
- 检查 Base URL 是否正确指向可用的 API 端点

### AI 记不住之前的对话

- 短期记忆保留最近 20 条，超过后旧对话会被新对话挤出
- 重要信息如果只在短期记忆中出现一次且不满足长期记忆的条件，可能不会被保存
- 可以在 `config/user.yml` 中显式填写关键信息，确保 AI 始终知道

### 气泡显示异常

- 气泡位置跟随猫咪窗口，如果猫咪在屏幕底部，气泡可能翻转到上方
- 气泡自动隐藏时间为 15 秒
- 超长内容可滚轮滚动，向上滚动时自动锁定位置

## 语音输入

### 语音输入没有文字

- 确认 `config/actions.yml` 中 voice 动作的 `trigger` 匹配你系统的语音输入热键
- Windows 默认语音输入热键是 `Win+H`，需要在设置中开启
- 程序模拟的是按键组合，不是直接录音，依赖系统输入法

### 语音输入出现上次的内容

- 程序有 generation 防残留机制，理论上不会出现此问题
- 如果出现，可能是输入法延迟过长（超过 700ms），尝试增大 `delay` 参数

## 截图

### 截图分析不工作

- 确认 API Key 支持 Vision 功能
- 截图间隔默认 30 秒，可在设置中调整
- 对话和舞蹈期间截图自动暂停，这是正常行为

### 截图占用太多 token

- 增大截图间隔（设置 → 外观行为 → 截屏分析间隔）
- 截图会自动缩放到最大 960px 宽度以节省 token
- 画面未变化时通过 dHash 去重自动跳过

### 截图文件占满磁盘

- 截图文件 7 天自动清理
- 存储在 `~/.ai-pad/screenshots/` 下按日期目录组织
- 如果需要手动清理，直接删除对应日期目录即可

## 设置

### 设置保存后没生效

- actions.yml 和 prompts.yml 保存后需要 gamepad_loop 下一个 tick 刷新（最多 80ms）
- 全局快捷键修改需要重启程序
- 其他设置即时生效

### 找不到配置文件

- 运行程序后查看设置窗口 → 关于标签页，会显示所有配置文件的实际路径
- 如果 exe 同目录没有 `config/` 文件夹，程序使用内置默认配置
- 可以手动创建 `config/` 文件夹并放入 yml 文件

## TTS

### TTS 没有声音

- 确认设置窗口中 TTS 语音已开启
- 确认系统音量未静音
- TTS 使用 Windows 自带的 SAPI 语音合成，使用系统默认语音
- 中文 Windows 默认为 Huihui 女声，可在 Windows 设置 → 语音中更改

### TTS 和 AI 回复不同步

- TTS 是异步播放的，新回复会打断上一次朗读
- TTS 不依赖网络，纯本地合成
