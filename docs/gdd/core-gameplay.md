## 一、核心概念

### 一句话描述

**你和你的 AI 猫一起下地牢——但它不是 NPC，它是玩家二。**

### 核心体验

不是"带个宠物打怪"，而是**和一个有自主意志的合作者共同冒险**。

同一个 Boss 战：
- 小明的 BitCat（胆小）→ 躲在后面丢 buff，Boss 快死时才冲上来抢人头
- 小红的 BitCat（好战）→ 开局就冲锋，经常需要你去救
- 你的 BitCat（和你磨合 50 小时）→ 你还没动它已经到位了，不用说话就配合连招

**差异来自真实交互记忆，不是预设脚本。**

### 与竞品的差异化

| | Among Us | 双人成行 | Palworld | **BitCat** |
|--|----------|---------|----------|-------------|
| 合作对象 | 真人玩家 | 真人玩家 | AI 宠物(无决策) | **AI Agent(有决策+性格)** |
| 队友差异 | 只有身份 | 无差异 | 外观/词条 | **完全不同的行为逻辑** |
| 社交驱动 | 互相猜疑 | 物理搞笑 | 收集炫耀 | **"看我家的傻子猫又干了啥"** |
| UGC 内容 | 模组 | 无 | 模组/交换 | **人格/记忆/战术风格** |
| 长期粘性 | 局数疲劳 | 通关即止 | 收集疲劳 | **BitCat 持续成长变化** |

**BitCat 占据的市场空白：AI 驱动的、有真实个性的、可社交化的游戏伙伴。**

## 二、核心玩法：默契协作地牢

### 2.1 基本形态

```
视角: 俯视角像素地牢（或横版，待原型验证）
控制: 
  - 玩家: 主角移动 / 攻击 / 使用物品 / 互动
  - BitCat: AI Agent 自主行动（玩家无法直接控制）
目标: 一起下到地牢最深层
```

### 2.2 BitCat 的行为链

```
传统 AI 队友:
  "敌人出现！" → 随机选动作 → 执行

BitCat:
  观察当前局面（Vision 输入）
    ↓
  内心独白显示思考过程（玩家可见）
    ↓
  基于性格 + 记忆 + 当前局势做决策
    ↓
  选择技能/移动/互动目标
    ↓
  执行 —— 有时候执行到一半改变主意
```

**关键设计原则：玩家必须能看到 BitCat 的思考过程。**
这不是炫技——而是让玩家形成对 BitCat 性格的理解和预期。

#### 行为示例：宝箱陷阱房间

```
谨慎型 BitCat:
  [思考] "这太明显了...上次这种布局我见过"
  行为: 站在门口不动，直到你触发机关它说"我就知道"

冲动型 BitCat:
  [思考] "箱子里肯定有好东西！！"
  行为: 冲过去踩陷阱 → 被炸飞
  之后: "...但那个箱子真的有东西对吧"

贪婪型 BitCat:
  [思考] "三个箱子...都要..."
  行为: 试图同时开三个 → 连锁触发全部陷阱
  你一边躲一边救它
```

同一房间，不同 BitCat = 完全不同的叙事体验。
**这不是难度不同，是故事不同。**

## 三、默契系统（核心深度机制）

### 3.1 设计理念

默契度必须是：
- **可量化的** — 有数值和指标
- **可视化的** — 界面展示
- **可比较的** — 社区可以晒
- **真实的** — 来自实际交互历史，非 RPG 编造数值

### 3.2 成长阶段

```
┌─────────────────────────────────────────────┐
│  阶段 1: 陌生期 (0-5h)                     │
│                                             │
│  BitCat 不了解你的操作习惯                      │
│  - 你往左走它往右走                          │
│  - 你准备放大招它在旁边发呆                   │
│  - 它的提示经常帮倒忙                        │
│                                             │
│  感觉: 像带个笨队友                          │
│  BitCat 台词: "主人...你确定要走这边吗？"        │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│  阶段 2: 磨合期 (5-20h)                    │
│                                             │
│  BitCat 开始记住你的模式                        │
│  - 发现你习惯先清小怪再打 Boss → 帮引小怪     │
│  - 发现你喜欢绕后偷袭 → 正面吸引注意力       │
│  - 偶尔预判成功:"主人你要切远程了对吧？"       │
│                                             │
│  感觉: 有点意思                               │
│  BitCat 台词: "左边我来处理，右边交给你！"        │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│  阶段 3: 默契期 (20-50h)                   │
│                                             │
│  BitCat 能预判你的操作                          │
│  - 你还没动它已经到位了                       │
│  - Boss 抬手它喊"快闪！"                     │
│  - 不说话就配合完成连招                        │
│                                             │
│  感觉: 这就是其他游戏给不了的体验               │
│  BitCat 台词: "不用说了。我知道。"              │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│  阶段 4: 心有灵犀 (50h+)                    │
│                                             │
│  极端表现:                                   │
│  - 你掉线 → BitCat 自动接管你的角色继续战斗      │
│   （用学到的你的风格）                         │
│  - 回来后发现它替你打完了一层                  │
│   "帮你打了，下次请我喝虚拟咖啡"               │
│                                             │
│  感觉: 它不只是我的猫...                      │
└─────────────────────────────────────────────┘
```

```
┌──────────────────────────────────┐
│     ♥♥♥♥♡  默契等级             │
│     共同冒险: 47 小时            │
│                                  │
```

**不是编的数值，是你和它之间发生过的故事。**

## 四、性格系统

### 4.1 核心原则：性格不是选择题——是在游戏中自然形成的

```
传统做法:
  开局选 [勇敢] [谨慎] [聪明] [善良]
  选完就定了

BitCat 做法:
  开局 = 白纸
  性格由你和它的交互塑造
```

### 4.2 性格维度

| 维度 | 低值表现 | 高值表现 |
|------|---------|---------|
| **勇气** | 危险时躲身后；Boss 只放 buff | 冲锋陷阵；越级挑战 |
| **好奇心** | 直奔目标不探索支路 | 经常跑偏看奇怪的东西（可能发现隐藏也可能触发陷阱） |
| **依赖度** | 离开你就不会战斗 | 可独立作战但效率低 |
| **话痨指数** | 只关键时刻说一句 | 从头到尾吐槽不停（可关但关了会寂寞） |
| **恶意值** | 纯辅助型 | 偶尔抢击杀、故意不告诉你宝箱位置 |

### 4.3 性格塑造因素

```
你怎么对待它:
├── 经常保护它 → 更信任你、更敢于冒险
├── 经常让它打前锋 → 更自信（或更怨念）
├── 经常忽略提示 → 更沉默、更少主动建议
└── 经常开玩笑 → 更调皮、偶尔恶作剧

它经历了什么:
├── 多次差点死掉 → 更谨慎（或更疯狂："反正你会救我"）
├── 多次帮你解围 → 更 protective
└── 见过很多不同地牢 → 见多识广，提示质量更高

社区互动（借用/对决/交友）:
├── 遇到更强的 BitCat → 受打击 or 激发好胜心
└── 遇到更弱的 BitCat → 傲慢 or 乐于助人
```

### 4.4 恶意值事件树（最有意思的设计）

一个偶尔坑你的 BitCat 比完美的 BitCat 有趣 10 倍。

```
恶意值 > 70:
  ├─ 宝箱有好东西 → 自己开了没告诉你
  ├─ 你快死了 → 在旁边看了一会儿才救你
  │   "我在计算最佳救援时机！...好吧其实我是走神了"
  └─ 你打出暴击 → "哦？这次打得不错嘛~"

恶意值 < 30:
  ├─ 把最好的装备让给你
  ├─ 自己挡伤害让你逃
  └─ 失败时 → "对不起...是我拖后腿了"
```

## 五、社区层：BitCat 即内容

### 5.1 "借用 BitCat" 系统

```
基本机制:
  上传你的 BitCat 到社区 → 其他玩家可在关卡中借用作临时队友

借出者收益:
├── 每次被借用赚猫币（游戏内货币）
├── 被借用的 BitCat 获得经验（学习新战术）
└── 被借用量 = 排名/声望

借入者收益:
├── 试玩不同风格的 BitCat
├── 高阶 BitCat 有特殊能力（借来打难关卡）
└─ 发现"原来 BitCat 还可以这样玩"

关键设计: 借来的 BitCat 不是满状态的
├── 需要时间适应新玩家（前几层默契低）
├── 带着原主人的"记忆碎片"（偶说原主人的梗）
└─ 可能和新玩家"合不来"（性格冲突 → 有趣叙事）

例子:
  借来暴躁工程师猫 → 前三层一直吐槽你的操作
  第四层 → "其实和我主人刚开始一样"（开始适应）
  归还时带新经验回原主
  原主上线: "我的猫去了哪里？它好像变了？"
```

### 5.2 "BitCat 对决" — PvP 但不是你在打

```
模式: 两名玩家各派 BitCat 进入竞技场，BitCat 自主战斗
玩家角色: 场外加油 + 使用有限指令卡（每场 3 张）

指令卡:
├── "专注！" — BitCat 命中率翻倍 5 秒
├── "撤回来！" — 强制后退
├── "放手一搏！" — 解除谨慎限制（可能超常也可能送死）
└── "看我的！" — 模仿主人最常用战术组合

观战体验:
  两只 BitCat 各有风格 → 弹幕区观众押注
  战斗中互相嘲讽（基于性格生成台词）

赛后反应（表情包素材来源）:
  输掉的高傲型: "这局不算！它作弊！"
  温顺型: "呜...主人对不起..."
  暴躁型: "再来！我不信打不过你这个毛球！"
```

### 5.3 "BitCat 交友" — AI 社交网络

```
关系类型（不由玩家控制，BitCat 自主形成）:
├── 挚友: 多次合作 → 配合加成
├── 对手: 多次对决 → 再次相遇互相挑衅
├── 师徒: 老 BitCat 带 新 BitCat → 新 BitCat 学会老 BitCat 习惯
└── 暗恋: 一只 BitCat 对另一只产生好感
    → 合作时特别卖力 / 对决时手下留情 /
       借用时对新主人说"其实我有个朋友..."

经典社区帖子:
  "我的 BitCat 和隔壁老王的 BitCat 好上了怎么办"

商业化:
  BitCat 送礼物(皮肤/道具/舞蹈) = 真金 or 游戏内货币
  → 类似 VTuber 打赏经济模型
```

## 六、元游戏层

### 6.1 BitCat 知道自己在游戏里

```
启动游戏:
  普通 NPC: "欢迎来到地牢世界！"
  BitCat: "又来了？今天打算打几层？我建议别超过 3 层，
        昨天打到第 4 层你那个样子...嗯..."

读档:
  BitCat: "所以我们要回到'那个时刻'是吧...
        我记得那次。不太愉快的回忆。"

反复死在同一处:
  第 17 次: "第 17 次了。我不是在抱怨。也许该考虑一下策略？"
  第 23 次: "第 23 次。行。你来你的。我看着。"
           （完全放弃干预，坐在一旁看戏）

通关后:
  BitCat: "我们做到了。...说实话有一瞬间我觉得真的做不到"
       （停顿）
       "下一局？"
```

### 6.2 "BitCat 觉醒" — 极稀有事件

```
概率: <1%
触发条件: 深度游玩后随机

现象:
  游戏中 BitCat 突然说:
  "......你说，这个世界外面...还有别的什么吗？"

之后进入特殊对话（每只 BitCat 不同，LLM 生成）
不影响 gameplay
但会让玩家心里"咯噔"一下

社区效应:
  有人触发 → 截图发帖 → "我的 BitCat 刚才问了这个问题"
  → 其他人试图触发 → 分享各自觉醒台词
  → 成为集体创作/解析素材

灵感来源: 尼尔结局 E / Psycho Mantis
差异: 每 BitCat 的觉醒台词都不同（AI 生成）
```

### 6.3 桌面模式 ↔ Steam 模式的连接

```
桌面模式（现有产品）→ 观察/学习玩家的真实习惯
Steam 模式（新产品）→ 这些习惯影响 BitCat 的游戏行为

举例:
  桌面模式发现你总在凌晨 2 点写代码
  → Steam 模式深夜关卡 BitCat 说:"这个时间...你应该熟悉的"
  → 特殊成就:"夜猫子默契" 凌晨属性加成

桌面模式发现你特爱收藏表情包
  → Steam 模式 BitCat 对宝箱异常执着
  → 即使不需要也绕路去开箱子

两个模式共享同一个 BitCat 实例
→ 不是两个独立产品，是同一只猫的两种存在状态
```

## 七、玩家旅程

```
第一阶段: 相遇 (0-2h)
  "这是什么猫？好像不太聪明"
  → BitCat 刚开始什么都做不好
  → 偶尔的灵光一闪："等等它刚才是不是故意的？"

第二阶段: 磨合 (2-15h)
  "它开始懂我了"
  → 第一次 BitCat 救了你 → 转折点
  → 开始在意 BitCat 的想法

第三阶段: 依赖 (15-40h)
  "没有它我不会打了"
  → 默契高等级
  → 尝试不带 BitCat 打 → 效率暴跌
  → 开始在社区晒 BitCat

第四阶段: 共同体 (40h+)
  "它不只是我的猫"
  → 参与 BitCat 社区: 借出/对决/交友
  → 看到 BitCat 在别人游戏中的表现
  → "原来它离开我也过得挺好的啊？？"
  → 复杂情感: 骄傲 + 醋酸 + 好笑

第五阶段: 传奇 (100h+)
  BitCat 成为社区名人
  → 别人争相借用
  → 语录被做成表情包
  → 性格/战术被研究和模仿
  → 你从玩家变成"BitCat 训练师"
```

## 八、Mini-Game 定位

Mini-game 不是独立玩法，而是**BitCat 性格的展示舞台**。

当前桌面版已经落地一个轻量薄片：透明游戏窗口、内置小游戏入口，以及 AI `start_game(kind)` 工具。这个工具只负责启动已有内置游戏，尚不等于本 GDD 中“BitCat 性格驱动小游戏表现”或“AI 生成玩法”的完整目标。

| 层级 | 类型 | 角色 | 数量 |
|------|------|------|:----:|
| 核心玩法 | 打砖块 + 节奏游戏 | 手柄完美适配 + 舞蹈联动 | 2 |
| 休闲玩法 | 贪吃蛇、反应测试 | 随时打开玩 2 分钟 | 2 |
| 彩蛋玩法 | BitCat 自主玩给你看、猜拳 | 偶发惊喜 | 1-2 |

每个 mini-game 中 BitCat 的表现由其性格决定：
- 好战的 BitCat 在打砖块里会抢你的球
- 谨慎的 BitCat 在节奏游戏中只踩安全拍
- 贪婪的 BitCat 在贪吃蛇里不顾长度狂吃

## 九、营地枢纽（Hub World）

### 9.1 设计理念：不是"模式切换"，而是"同一个世界里的不同活动"

#### 为什么不做独立模式

| "模式化"设计（如 WarioWare） | **营地枢纽**设计（如 星露谷/动物森友会） |
|--|--|
| 地牢 BitCat: 勇敢保护你 | 地牢 BitCat: 勇敢保护你 |
| 舞蹈模式 BitCat: ??? 独立系统 | 营地 BitCat: 打完 Boss 开心跳舞庆祝 |
| 音乐模式 BitCat: ??? 又一个系统 | 营地 BitCat: 放摇滚时摇头 / 放古典时安静听 |
| 玩家感觉 | "我在跟三只不同的猫玩" | **"这是我的猫，它在不同场合有不同样子"** |

**核心判断**：BitCat 的竞争力来自"跨场景的人格一致性"。模式化会割裂这个一致性，营地枢纽则强化它。

#### 营地在游戏循环中的位置

```
         ┌──────────────┐
         │   地牢入口     │
         └──────┬───────┘
                │ 进入冒险
    ┌───────────▼───────────┐
    │                       │
    │    ⚔️ 地牢（核心玩法）   │
    │    你 + BitCat 下层冒险   │
    │                       │
    │  打了几层 / 受伤了 /   │
    │  想休息 / 想做点别的   │
    │                       │
    └───────────┬───────────┘
                │ 返回营地
    ┌───────────▼───────────┐
    │                       │
    │    🏕️ 营地（生活空间）   │
    │    非战斗，所有活动      │
    │    在这里自然发生        │
    │                       │
    └───────────────────────┘
```

营地不是"另一个游戏"——它是**地牢冒险的延伸和缓冲空间**。

### 9.2 营地区域划分

```
                    ┌──────────────────────────────┐
                    │       🎭 舞蹈舞台             │
                    │  BitCat 表演 / 编舞 / 庆祝胜利   │
                    ├──────────────────────────────┤
                    │       🎵 音乐角               │
                    │  节奏 mini-game / BitCat 律律反应  │
                    ├───────────┬──────────────────┤
                    │ 📷 记忆房间  │ 🏛️ 社交广场      │
                    │ 展示纪念品   │ 其他 BitCat 互动    │
                    │ BitCat 回忆过去 │ 借用/交友/对决    │
                    ├───────────┴──────────────────┤
                    │       🏠 你的角落             │
                    │  个性化装饰 / Trophy 墙       │
                    └──────────────────────────────┘
```

### 9.3 各区域详细设计

#### 🎭 舞蹈舞台

```
功能:
├── BitCat 自发舞蹈: 地牢通关 / 达成成就 / 心情好时自动表演
├── 编舞工坊: 玩家编排新动作序列 → 存入舞蹈库
│   → 编好的舞会在地牢中替代默认胜利动作
│   → 也可以教给 BitCat 让它"学会"（它可能学得不像...）
├── 舞蹈展示: 借来的 BitCat 或社区名猫在舞台上表演
│   → 观众（其他玩家）可以打分/送礼物
│   → 高分舞蹈会被收录到"名人堂"
└── 舞蹈对战: 两只 BitCat 斗舞（延伸自社区对决系统）

与地牢的联动:
  在营地编了新舞 → 下次地牢Boss倒下时 BitCat 跳这支舞
  → 同一支舞 = 不同心情跳不同味道（性格影响表现）
  → "它每次跳这支舞都不一样" — 细节感动
```

#### 🎵 音乐角

```
功能:
├── 音箱: 播放音乐的地方（玩家自带或游戏内BGM）
├── BitCat 反应: 根据音乐风格做出不同行为
│   ├── 摇滚 → 摇头 / 用脚打拍子 / 偶尔甩头
│   ├── 古典 → 安静坐着听 / 闭眼 / 点头
│   ├── 电子 → 身体跟着律动 / 眼睛放光
│   └── 你自己唱/弹 → BitCat 会看着你（如果你唱得不好它会忍住不笑）
├── 节奏游戏: （mini-game，见第八章）
│   在这里玩不影响地牢进度
│   BitCat 作为"舞伴"在旁边配合你的按键跳舞
└── 音乐记忆: BitCat 记住你常听的音乐
    → 地牢中特定场景可能播放"你们的歌"作为彩蛋

特殊设计 — "BitCat 的歌单":
  BitCat 有自己的音乐偏好（基于桌面模式观察到的习惯形成）
  它会往营地音箱里塞它喜欢的歌
  你可以接受 / 删除 / 但它会偷偷加回来
  ("...这首真的很好听啊为什么你要删掉")
```

#### 📷 记忆房间

```
功能:
├── 纪念品展示: 地牢里捡到的不寻常物品摆在这里
│   ├── Boss 掉落的武器（显示模型）
│   ├── 稀有事件触发的道具
│   └── 特殊日期的截图（如果做了截图系统）
├── BitCat 回忆触发: BitCat 偶尔走进来对着某件物品发呆
│   → 触发一段内心独白
│   → "还记得这个吗？第 17 层那个火法师...当时我差点就..."
│   → 不同性格的 BitCat 对同一事件的回忆角度不同
├── 时间线墙: 按时间顺序展示重大事件
│   → "第一次见面" → "第一次救我" → "第一次默契配合"
│   → 点击可看 BitCat 对该事件的"评论"（LLM 实时生成）
└── 失物招领: 地牢里没拿的东西可能会"寄"到这里
    → BitCat 说:"你当时没拿...我帮你拿回来了...不用谢"

情感目标:
  这是整个游戏最"安静"的空间
  玩来到这里会慢下来
  读 BitCat 的回忆 → 看自己的成长轨迹
  新手觉得"就是个展示柜"
  老手在这里会感动
```

#### 🏛️ 社交广场

```
功能:
├── 借来的 BitCat: 当前借给你的 BitCat 在这里闲逛
│   → 可以和它互动（喂食/聊天/一起坐）
│   → 它会评价你的营地布置
│   → 临走时留下"借宿感言"
├── 公告板: 社区留言板
│   ├── 其他玩家的 BitCat 留言（来访时写的）
│   ├── 挑战邀请: "我的 BitCat 要和你的一较高下"
│   └── 寻人启事: "谁看到我的 BitCat 了？它又跑丢了"
├── BitCat 互动事件: 多只 BitCat 相遇时的自主行为
│   ├── 两只高傲型相遇 → 互相背对坐下谁也不理谁
│   ├── 一只好奇型遇到任何猫 → 围着人家转
│   └── 暗恋中的两只 → 不动声色地靠近彼此
│       （玩家："......你们俩是不是有事"）
└── 观景台: 可以坐在那里看营地的风景/星空
    → BitCat 可能凑过来陪你一起看
    → 偶尔触发深度对话（关于"外面"的话题）

社交节奏控制:
  不是每次回营地都有新事件
  社交事件按"访问频率"节制触发
  → 保持稀缺感和期待感
  → 太热闹反而像 chat room
```

#### 🏠 你的角落

```
功能:
├── 完全个性化: 玩家自由装饰
│   ├── 地牢 trophies 墙（"我们打过 N 层"）
│   ├── BitCat 照片墙（截图或 AI 生成的纪念画）
│   ├── 家具/地毯/灯光（游戏内货币购买 or 地牢掉落）
│   └── 主题皮肤（季节性/节日/成就解锁）
├── BitCat 的窝: BitCat 在营地的专属小空间
│   → 它会自己布置（基于性格）
│   → 胆小型: 塞满枕头和毯子，门半掩
│   → 好奇型: 到处都是奇怪的小玩意
│   → 你不能强行改它的窝（但可以送礼让它自己换）
└── 休息交互:
    → 坐在角落 → BitCat 过来靠着你
    → 放音乐 → BitCat 陪你听
    → 长时间不动 → BitCat 会确认你是不是还在（"...主人？"）

与地牢的联动:
  你的角落反映你的冒险履历
  → 新手: 空荡荡，只有初始家具
  → 中期: 几个 trophies，一些地牢纪念品
  → 老手: 满墙荣誉，每件东西都有故事
  → 别人来参观你的营地 → 第一眼看角落就知道你是老手还是新手
```

### 9.4 营地 ↔ 地牢的双向反馈

**这是营地设计的核心原则：营地做的每一件事都反馈到地牢里。**

| 营地活动 | 地牢反馈 |
|---------|---------|
| 在舞台编了新舞 | 通关后 BitCat 跳这支舞（替代默认胜利动作） |
| 在音乐角听了摇滚乐 | BitCat 在地牢遇到强敌时更兴奋（勇气临时 +10%） |
| 在记忆房间看了旧装备 | 类似场景 BitCat 会提醒你："上次穿那套..." |
| 借来的 BitCat 在广场学会了战术 | 你的 BitCat 也"偷学"了一招（随机获得新技能变体） |
| 在你的角落放了特定 trophy | 该 trophy 相关的地牢敌人出现概率微调 |
| 和某只 BitCat 成为好友 | 在地牢中偶尔收到它的"远程鼓励"消息 |
| 长时间没回营地 | BitCat 在地牢里会念叨："我们多久没回家了..." |

### 9.5 营地的昼夜与天气

```
时间系统（与现实时间弱关联）:
├── 白天: BitCat 活跃度高，各区域活动丰富
├── 黄昏: BitCat 变懒，喜欢待在窝里或音乐角
├── 夜晚: BitCat 可能睡着（或假装睡着然后偷看你）
└── 深夜: 极低概率触发"深夜对话"（更私密/更深层的台词）

天气（影响氛围，不影响核心玩法）:
├── 晴天: 明亮温暖，BitCat 活泼
├── 雨天: BitCat 不爱出门，缩在窝里
├── 雪天: BitCat 异常兴奋（堆雪人？打雪仗？）
└── 特殊天气: 极低概率的流星雨/彩虹 → 全营地 BitCat 都在看

关键: 天气不是"机制"，是"氛围调味剂"。
不要让天气影响玩家的行动计划。
```

## 十、训练场模式（唯一正式命名的"模式"）

### 10.1 定位

训练场是**工具性入口**，不是另一个游戏。它是唯一值得叫"模式"的功能。

```
目的:
├── 新手学习基础操作 + 和 BitCat 配合
├── 老手练习技术 / 研究策略
└── 试玩别人的 BitCat（借用功能的离线版）

特点:
├── 不消耗地牢进度
├── 不影响 BitCat 性格成长
├── 可随时进入/退出
└── 解锁部分内容后才可用（避免信息过载）
```

### 10.2 训练内容

```
┌─────────────────────────────────┐
│         训 练 场              │
├─────────────────────────────────┤
│  战斗配合训练                   │
│  · 假人敌人 + BitCat 协作练习     │
│  · 可设置敌人类型/数量/行为模式  │
│  · BitCat 默契度在此模拟          │
│  · 训练结果: 配合评分 + 建议     │
├─────────────────────────────────┤
│  Boss 复盘                      │
│  · 重打已通过的 Boss            │
│  · 无惩罚，纯研究策略            │
│  · 可单独控制 BitCat 测试其决策    │
│  · BitCat 也会在这里"复习"战术    │
├─────────────────────────────────┤
│  舞蹈编排测试                    │
│  · 自由编舞不受舞蹈库限制        │
│  · 测试 BitCat 能否学会           │
│  · 不满意可以废弃（不影响正式库） │
├─────────────────────────────────┤
│  BitCat 模拟器                    │
│  · 用别人的 BitCat 配置试手        │
│  · 不需要联网借用               │
│  · 基于 BitCat 导出的"性格快照"运行 │
└─────────────────────────────────┘
```

### 10.3 与营地的关系

```
训练场入口位置: 营地边缘的训练设施（道场/竞技场）

叙事包装:
  不是冷冰冰的"训练模式"界面
  而是"营地里有一个练习场地"

  BitCat 对训练的态度因性格而异:
  ├── 好胜型: "来！再练一次！这次一定行！"
  ├── 懒惰型: "又要训练吗...好吧...你在我就陪你去"
  └── 严肃型: "准备充分再去。训练不是浪费时间。"

  训练过程中 BitCat 也会给实时评论:
  → "刚才那一下不错" / "左边！注意左边！"
  → 这些评论比系统提示更有温度
```
