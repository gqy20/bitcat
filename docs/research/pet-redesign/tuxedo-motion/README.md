## 交付

- `idle-atlas.png`：四姿势横向图集，每帧 96×96，身体固定，仅切换眼睛和尾尖。
- `walk-atlas.png`：八帧横向行走图集，每帧 96×96，每帧 140ms，周期 1120ms。
- `idle-preview.gif`、`walk-preview.gif`：192px 放大的循环预览。GIF 编码时间有量化，精确时长以 `animation.json` 为准。
- `animation.json`：两段循环的时间轴和行走位移，研究规格，不是完整应用宠物包。
- `walk-parts.png`：内置 image_gen 生成的身体与四肢分层素材。
- `motion.js`：Canvas 分层动画与预览导出；`prompts.json` 保留生成提示词。

## 方法与取舍

直接生成八帧后，近侧前爪仍未可靠地前后交替，第二次修订也未达到要求。`walk-generated-study.png` 留作失败样本，不参与最终播放。
最终采用生成图的独立身体与四肢，由 Canvas 作变换和合成。固定身体图避免脸和花纹漂移；四条腿相位错开，落地阶段恒速推蹬，抬脚阶段平滑回收。

每周期落地占比 0.625，单次推蹬距离 16 逻辑像素，根节点每周期移动 16 / 0.625 = 25.6 像素。移动与帧播放共用离散相位，使落地脚掌锚点相对地面保持固定。栅格化仍可能有约一像素的取整误差。
到达画面左边后从右侧重新进入，只用于移动检查，不表示转身动画已完成。

## 检查结果

- 浏览器连续播放覆盖全部八个行走帧。
- 待机三张变化帧在眼睛/尾巴区域之外，与基准帧逐像素差异均为 0。
- 落地锚点的相邻帧世界坐标误差小于 1e-12 逻辑像素（纯几何模型，不代表栅格边缘绝对无抖动）。
- 暂停后位置固定；支持逐帧、半速、80/96/192px、深浅背景及图集下载。
- 系统减少动态效果偏好下默认暂停；页面隐藏时停止推进时间。

## 本轮边界

这是分层动画验证版，具有轻微纸偶感。四肢使用整段素材变换，尚未逐关节绘制。身体朝向及坐姿到行走的衔接还需打磨，不包含睡眠、转身或坐起过渡。
96×96 是工作画布，不宣称已经达到严格 48×48/64×64 有限色板的最终像素画验收。
素材导出来源是预览页面的 `motionPreview.exportAtlas(kind)`，无需重新调用生成模型。
应用资源、默认宠物及设置页均未改动。
