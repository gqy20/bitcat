# 第二轮精修

内置 image_gen 对十张原图分别编辑，输出十张六姿势 PNG，原图保留。逐张提示词见 `prompts.json`。
打开 `index.html` 可按猫咪切换初版/精修对比，并切换浅色、深色、蓝色背景和 80/96/144px 预览画布。

## 本轮变化

- 简化局部毛发碎纹，强化大色块和五官轮廓。
- 黑猫增加面部、肩背和四肢的明暗区分，白猫保持蓝灰轮廓。
- 保留每类猫原有的眼色、体型、主要花纹与六姿势顺序。
- 测量真实主体边界供小尺寸预览使用，不把生成图直接等分裁切。比较时采用同一比例、底部对齐，保留睡姿较低的体型。

## 已完成的检查

十张均为 1536×1024 RGBA，均检测到六个主要连通主体，画布边缘的 alpha≥128 像素为零。完整数据见 `audit.json`。
脚本 `../audit-assets.py` 只读取图像，不修改素材；运行需 Pillow、NumPy、SciPy，同时更新 JSON 与预览所需 JS 数据。

透明背景判断已修正：原图预览中大面积光晕主要存在于 alpha=0 的隐藏颜色里，在浏览器真实合成时不显示。不能仅凭忽略透明通道的预览判断背景残留。

## 尚未达到正式动画验收的部分

- 两张走路姿势虽然有变化，近远侧腿交替仍未稳定满足完整步态要求，需要单独绘制关键接触姿势与过渡帧。
- 待机与眨眼的身体不完全逐像素相同。下一步应固定同一身体，仅替换眼睑区域。
- 仍是高分辨率像素风，未通过严格 48×48 逻辑网格和有限色板验收。
- 深背景下黑猫整体依然偏暗；保留黑色身份的同时，还可进一步增强边缘色阶。
- 连通主体边界不等于每根分离胡须的边界，预览加了外扩留白，完整原图始终可下载。

本轮不修改应用资源目录、设置和默认宠物。产品时刻为陪伴/互动，应用入口变化 +0 / -0，无权限变化。
