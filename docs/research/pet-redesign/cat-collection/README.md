# 十类猫关键帧设计

共 10 张 1536×1024 PNG，每张六个关键姿势，共 60 个姿势设计。
使用内置 image_gen，每类独立生成，统一参考上级目录的 `tuxedo-selected-concept.png`。
完整提示词保存于 `catalog.json`；`index.html` 可直接打开浏览和下载。

这里的「类」包含毛色类型与品种：橘猫、狸花、三花、奶牛、纯黑、白猫、英短蓝猫、暹罗、布偶、缅因。

## 帧序

| 位置 | 姿势 | 设计用途 |
|---|---|---|
| 上左 | 待机 | 固定角色轮廓、眼色、花纹 |
| 上中 | 眨眼 | 闭眼关键姿势 |
| 上右 | 迈步 A | 侧身行走的一个接触姿势 |
| 下左 | 迈步 B | 行走第二个姿势，正式制作时需核对四肢交替 |
| 下中 | 蜷睡 | 收拢身体、头靠近爪子、尾巴包围身体 |
| 下右 | 开心抬爪 | 短暂互动反馈 |

## 造型区别

| 类型 | 主要特征 |
|---|---|
| 橘猫 | 橘色条纹、浅色胸口、琥珀眼 |
| 狸花 | 棕灰底色、深条纹、绿眼、灵活体型 |
| 三花 | 白底橘黑色块、不对称面部花纹 |
| 奶牛 | 大面积白色、黑色斑块、黑尾白尖 |
| 纯黑 | 深炭色毛、金眼、修长尾巴 |
| 白猫 | 白毛、浅紫灰阴影、蓝眼 |
| 英短蓝猫 | 圆脸、小耳、粗短尾、铜色眼 |
| 暹罗 | 修长身体、深色面罩与四肢、蓝眼 |
| 布偶 | 长毛胸口、倒 V 白脸、蓬松尾巴 |
| 缅因 | 耳尖毛、宽口鼻、浓密胸毛、大尾巴 |

## 验收范围与后续制作

本批为造型及动作关键帧设计稿，未替换应用资源，也不宣称是可直接切片播放的最终精灵表。
已逐图查看六种姿势与品类特征，并检查十张文件可读取且尺寸一致。
第二轮核对修正：预览器显示的大面积光晕主要是完全透明像素里的隐藏 RGB，浏览器实际合成不显示该背景。PNG 仍有半透明边缘，最终素材需检查边缘及像素网格。
黑猫在深背景对比偏低；正式精修优先改善轮廓可读性。

正式接入前需要：检查透明边缘；统一逻辑像素网格、色板与显示尺寸；固定同一只猫的花纹；对齐脚底和角色中心；核对走路前后腿交替并补过渡帧。坐姿与眨眼也需稳定身体，避免切换时跳动。

第二轮十张精修稿及对比预览见 [v2/index.html](v2/index.html)，提示词见 [v2/prompts.json](v2/prompts.json)，检查结果见 [v2/audit.json](v2/audit.json)。初版保留。

## 产品自检

- 时刻：陪伴与互动。
- 四个疑问：不适用，本批为宠物外形和动作设计。
- 预算：应用入口 +0 / -0，文件仅在研究目录。
- 文案：未变更应用文案。
- 恐慌测试：不涉及权限和默认值。
