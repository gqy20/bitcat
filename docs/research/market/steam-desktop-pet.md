## 二、逐品深度分析

### 2.1 虚拟桌宠模拟器 (VPet) — 品类霸主

**App ID**: 1920960 | **开源**: github.com/LorisYounger/VPet | **授权**: MIT

**核心功能：**
- 200+ 互动动画 — 摸头/摸身子/提起/跳舞/爬墙
- 投喂系统 — 喂食/饮料
- 工作系统 — 桌宠"工作"赚钱
- C# 代码插件 — 可编写插件添加新功能（Live2D/Spine、闹钟/记事板等），"几乎无所不能"
- 完全免费，无内购

**DLC 策略：** 仅 2 个免费 DLC（猫猫皮肤包 + MOD 制作器）

**系统要求：** 最低 Win7 / 双核 / 200MB RAM / 1GB 存储

**用户好评重点：**
- "QQ宠物精神继承者"，养女儿既视感
- 免费做到这个程度"好得不能再好"
- 创意工坊 MOD 生态极强，用户大量求特定角色 MOD
- 大量 200-1700 小时深度用户
- 上班挂机摸鱼神器

**用户差评痛点：**
- **存档丢失** — "挂的好好的隔天存档就没了，一切归零"（494h 玩家）
- **无法卸载/残留** — "移除不了，和蟑螂一样阴魂不散"
- **启动卡死** — "退出得卡半天，任务管理器都看不见进程"
- **依赖 Steam 运行** — 不能像 Wallpaper Engine 那样脱离 Steam

### 2.2 AI桌面宠物 — 本地 AI 桌宠

**App ID**: 4227700 | **技术栈**: Electron + Python | **授权**: Live2D Cubism SDK 正版

**核心功能：**
- Live2D 桌宠 — 无边框透明窗口，视线追踪，表情/动作交互
- **内置本地 LLM** — 无需 API Key/Token/联网
- 本地"酒馆" AI 角色扮演 — 兼容主流人设卡，世界书，对话分支，100+ 内置人设卡
- 语音双引擎 — SenseVoice(中英日韩) + Whisper(近百种语言)
- 100+ 内置音色 + **音色克隆**（参考音频→指定声线）
- Steam 创意工坊 — Live2D 模型/人设卡/世界书一键分享
- 30 种界面语言，开箱即用

**安装大小：~20GB**（Electron + Python 库 ~7GB + 各种 AI 模型）

**系统要求：** 推荐 Win11 / i5-12400 / 16GB RAM / RTX 3060 / 10GB 存储

**用户好评重点：**
- 本地部署体验好，AI 响应快，无需联网
- 开发者积极回应，当天修复问题
- 酒馆玩法自由度高，可自己创建编辑角色
- 音色克隆有特色

**用户差评痛点：**
- **20GB 安装包** — Electron+Python，"打开比 PPT 还卡"
- **桌宠与 AI 联动弱** — "桌宠目前只能算个彩头"，主要功能还是聊天
- **Live2D 模型少** — 创意工坊内容还在积累
- **缺少使用说明** — 新手不知道如何创建人设卡/世界书
- **显存要求高** — 部分用户因显存不够无法运行
- **¥52 定价偏贵** — 与竞品对比

## 五、用户需求洞察

### 5.1 用户真正在夸什么（按频次排序）

1. **"生命感"/陪伴感** — Lofi猫打字时猫跟敲键盘、熄屏蜷起来睡觉，这种细节比 AI 对话更打动人
2. **免费且内容丰富** — VPet "免费做到这个程度已经好得不能再好"
3. **MOD/创意工坊生态** — 自定义角色、皮肤、插件，社区产出延长生命周期
4. **长时间挂机粘性** — 上班挂机、摸鱼神器，200-1700 小时深度用户大量存在
5. **开发团队响应速度** — Lofi猫当天修复，AI桌面宠物当天回复，用户非常看重

### 5.2 用户真正在骂什么（按严重程度排序）

1. **开发跑路/停更** — Ai Vpet SSL 证书过期，最致命的口碑杀手
2. **存档丢失** — VPet 挂了好好的隔天一切归零（494h 玩家），信任崩塌
3. **安装包巨大/卡顿** — AI桌面宠物 20GB，"打开比 PPT 还卡"
4. **AI 额度消耗/付费争议** — Molili 用户反复吐槽"币贵/用得快"
5. **桌宠与 AI 联动弱** — "桌宠目前只能算个彩头"，两个系统割裂
6. **纯挂机无互动** — 桌面小猫娘"挂机像是把一个游戏挂五遍"
7. **系统割裂** — 钓鱼不能给烹饪提供食材，各系统不联动
8. **缺少文档/引导** — 新手不知道如何创建人设卡/世界书

### 5.3 用户明确期待但未满足的需求

- **宠物主动互动** — Ai Vpet 用户希望"时不时自己说话"
- **桌宠与 AI 联动** — AI桌面宠物用户希望桌宠不只是"彩头"
- **效率工具集成** — Lofi猫证明了番茄钟+白噪音+待办的组合价值
- **跨系统联动** — 钓鱼→烹饪→喂养，而非各系统孤立
- **社区/轻社交** — 在线自习室、互相帮忙开礼盒

## 六、8Bit Cat 独特定位分析

### 6.1 竞品空白区（我们的独特组合）

| 能力 | 竞品覆盖 | 我们的定位 |
|------|----------|-----------|
| **手柄交互** | 0/9 竞品有 | SDL2 80ms tick，唯一手柄驱动桌宠 |
| **屏幕感知+Vision** | 1/9 有基础截图 | 定时截图+Vision API 持续场景理解 |
| **像素风精灵** | 2/9 像素风(均为低价品) | 128x128 Canvas 动画，像素审美差异化 |
